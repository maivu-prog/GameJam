# Rusty Fishing Unity port

Open `Assets/Scenes/SampleScene.unity` and press Play. `GameBootstrap` creates the complete portrait game runtime automatically.

## Ported systems

- 180-second day and 180-second night, Rest-at-port dawn skip, night monster warning.
- Accelerating/decelerating boat, four ports, three safe-speed obstacles, persistent hull damage and paid harbor repair.
- Nine fish species with unique sprites/stats/depths, 360-degree hook control, collision damage, capacity and catching.
- Persistent JSON progression: coins, day, cargo freshness, four upgrade tracks, fish sale multipliers by port.
- Harbor market/upgrade screen and sea HUD built from exported mockup elements; all runtime copy is English.
